# 验证与验收

应用检查为 `pnpm run typecheck`、`pnpm run lint`、`pnpm run build`，必须在本地 Linux 文件系统执行。生产启动为 `pnpm start`，默认端口 3113，健康探针 `/` 返回 200。命令的实际时间和退出码见 `.tpl/reports/verification.json`；未执行项必须有原因。

浏览器验收使用真实运行页面，检查 PC 1440×1000、平板 834×1180、手机 390×844 和 320px 窄屏。配置视口、页面 innerWidth、扣除滚动条后的宽度和截图实际解码尺寸分别记录，不能放大截图冒充目标尺寸。

逐页检查中英文标题、站内导航、图片加载和横向溢出。检查语言切换保留 query/hash、手机菜单 Escape/焦点/背景锁恢复、FAQ、分类、定价和本地表单。动效按 MOTION.md 实际触发并观察初始、运行、结束；循环效果观察持续、暂停和恢复；视频必须确认 currentTime 推进。

PC 实际滚动和拖动滚动条；平板/手机确认滚动到页脚且无滚动槽。内部滚动区域单独检查。减少动态效果需要真实偏好环境验证；只读源码不能当作已通过运行验收。

`.tpl/assets/` 保存三端各四张展示截图及实际尺寸记录。页面改版后更新截图。格式命令 `node .tpl/tools/check.mjs .` 读取源码和 Git 索引，不代替应用检查。报告 sourceDigest 绑定排除 reports 的索引文件工作树字节，源码变更后重新验证并刷新报告。

素材解码不证明版权；动画参数研究不证明逐帧运行完全一致。真实未验证项与差异保留在报告 limitations，不把 HTTP 200 或构建成功写成完整视觉验收。

滚动锁回归使用 `pnpm run test`，以 Node 内置测试器验证预加载与菜单的两种释放顺序、重复清理及初始状态恢复；实际浏览器另复测加载期间打开菜单、加载结束后关闭菜单，不能用单元测试代替。
